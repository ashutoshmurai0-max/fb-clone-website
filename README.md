# Facebook Clone Website

This is a clone of the Facebook website, built as part of a Git Tutorial project. The goal was to practice front-end development along with version control using Git and GitHub.

## About the Project

This project replicates the basic layout and design of Facebook's homepage, including elements like the navigation bar, login section, and overall UI structure. It was created primarily as a learning exercise to understand HTML, CSS, and Git workflow (commits, branches, merging, and pushing to a remote repository).

## Features

- Facebook-style navigation bar
- Login/signup section layout
- Responsive design basics
- Clean and simple UI structure

## Tech Stack

- HTML
- CSS
- JavaScript (if used)

## What I Learned

- Structuring a real-world website layout using HTML/CSS
- Using Git for version control (init, add, commit, push)
- Working with GitHub repositories
- Basic branching and merging workflow
